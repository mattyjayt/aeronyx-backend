# Configuration

There are two places to configure the backend:

1. **`.env`** in the project root: settings for the Python API.
2. **`mediamtx/mediamtx.yml`**: settings for MediaMTX and the camera capture command. This file is generated by `install.sh`.

## `.env`

Loaded with `python-dotenv` when the modules are imported. `.env` is git-ignored.

| Variable | Required | Default | Used by | Description |
|---|---|---|---|---|
| `MQTT_BROKER` | yes | — | `mqtt_server.py` | Broker hostname, e.g. `xxxx.s1.eu.hivemq.cloud` |
| `MQTT_PORT` | yes | — | `mqtt_server.py` | Broker port. TLS is always on, so this is normally `8883`. **If it's missing, the app crashes on import** (`int(None)`) |
| `MQTT_USERNAME` | yes | — | `mqtt_server.py` | Broker username |
| `MQTT_PASSWORD` | yes | — | `mqtt_server.py` | Broker password |
| `MQTT_SENSOR_TOPIC` | yes | — | `mqtt_server.py` | Topic to subscribe to for sensor readings |
| `CAMERA_RTSP_URL` | no | `rtsp://localhost:8554/stream` | `camera_stats.py` | Stream the fps monitor reads |

Example:

```sh
MQTT_BROKER=xxxxxxxx.s1.eu.hivemq.cloud
MQTT_PORT=8883
MQTT_USERNAME=aeronyx-backend
MQTT_PASSWORD=change-me
MQTT_SENSOR_TOPIC=aeronyx/sensors
```

## Constants in code

These are not environment variables; change them in the source.

**`src/aeronyx_backend/camera_stats.py`**

| Constant | Value | Meaning |
|---|---|---|
| `FPS_WINDOW` | `2.0` s | Length of the rolling window fps is averaged over |
| `OPEN_TIMEOUT` | `5.0` s | Time allowed to connect to the RTSP stream |
| `READ_TIMEOUT` | `2.0` s | Time allowed between packets before the connection counts as dead |
| `RECONNECT_DELAY` | `2.0` s | Pause before reconnecting after a failure |

**`main.py`**

- WebSocket push interval: `0.5` s (`asyncio.sleep(0.5)` in each handler).

**`backend.sh`**

- Uvicorn runs with `--reload --host 0.0.0.0` on the default port `8000`.

## MediaMTX (`mediamtx/mediamtx.yml`)

`install.sh` copies the stock `mediamtx.yml` to `mediamtx.yml.original`, then writes `mediamtx.yml` as the stock file with its `paths:` section replaced by:

```yaml
paths:
  stream:
    runOnInit: >
      ffmpeg -hide_banner -loglevel error -nostats
      -f v4l2 -input_format mjpeg -video_size 1920x1080 -framerate 30
      -i /dev/video0
      -c:v libx264 -preset ultrafast -tune zerolatency
      -pix_fmt yuv420p -b:v 2M -g 30
      -f rtsp rtsp://localhost:$RTSP_PORT/$MTX_PATH
    runOnInitRestart: yes

  all_others:
```

Everything else is the MediaMTX default. That includes the ports: RTSP `8554`, WebRTC `8889`, HLS `8888`. The MediaMTX control API (`:9997`) and metrics (`:9998`) are disabled.

> **Re-running `install.sh` overwrites `mediamtx.yml`.** To change the capture settings permanently, edit the heredoc in `install.sh` as well as (or instead of) the generated file.

What each capture option does is explained in [video-streaming.md](video-streaming.md#capture-pipeline).
